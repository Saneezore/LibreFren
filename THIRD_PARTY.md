# Third-party material

The repository GPL-2.0 license covers original LibreFren code and writing. It does
not relicense upstream source, documentation, firmware or libraries.

The locally downloaded upstream repositories retain their own license files
and notices. They are research inputs and are not bundled into the AppImage.
Source metadata contains attribution links and pinned commits. The local
SQLite database indexes upstream documentation for research; it is excluded
from the release artifact. Consult each document's license before copying or
redistributing its text.

Libreboot website colour values are taken from its CC0 `global.css`:
https://libreboot.org/global.css . The companion uses an original terminal
icon and does not claim upstream endorsement.

The frozen application includes Python and libraries selected by PyInstaller.
Python is distributed under the PSF license; PyInstaller has its own license
and bootloader exception. Distribution-specific library copyright notices
are collected during packaging where available. Review the final release's
dependency/license inventory before public redistribution.
